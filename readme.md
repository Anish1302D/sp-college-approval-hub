# S.P. College Approval and Workflow Management System

A React and Vite frontend prototype for managing approval workflows at S.P. College.

## Prerequisites

- Node.js 18 or newer
- npm

## Getting Started

```bash
npm install
npm run dev
```

The development server will print the local URL, normally `http://localhost:3000/`.

## Available Scripts

- `npm run dev` starts the Vite development server.
- `npm run build` creates a production build.
- `npm run preview` serves the production build locally.
- `npm run lint` runs ESLint when configured in the project.

## Project Structure

- `src/components` contains shared layout, modal, and UI components.
- `src/pages` contains role and workflow screens.
- `src/context` contains shared application state.
- `src/data` contains local mock data used by the prototype.

## Notes

The current implementation is a frontend prototype. Backend persistence, authentication, and production deployment are not included yet.
